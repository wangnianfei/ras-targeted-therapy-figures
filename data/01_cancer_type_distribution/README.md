# Figure 1 - cancer-type distribution

- cancer_type_kras_alleles.csv - per cancer type: sequenced samples, mutant samples, counts by allele (KRAS), and the NRAS/HRAS table.
- codon_share.csv - codon-level shares used in the labels.
- cbioportal_sample_cancertype.json - sample to cancer-type map from cBioPortal.

Source: MSK-IMPACT 2017 (msk_impact_2017), 10,945 samples. Denominators are sequenced samples of each type.
